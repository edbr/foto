# Stories / Histórias
Bilingual English/Portuguese collection of place-based stories. Home links to /trips/sertao; more paths may be added later. A route overview sits at the top right of each cover. No invented archive, shop, dates, authors or extra collections. Prefer stories, paths, discovery / histórias, caminhos, descobertas; avoid foto and viagem in visible copy.

## Approved design direction for redesign
Inspired by MAM Rio and Magnum, with the museum editorial feeling requested through MoMA. MAM extraction: flat achromatic gallery wall, oversized sans typography, unframed sharp artwork, small neutral labels. Magnum extraction: photograph-first editorial rhythm, white space, contact-sheet rules and square images. MoMA extraction returned no style guide; use only user intent for that reference.
Use Inter/system-ui/Arial sans throughout redesigned chrome and display. White #ffffff page, black #171717 text and active controls, #666666 muted, #dddddd thin borders, #f0f0f0 subtle surfaces. Gray locator land #e4e6e8, Brazil #c8cdd2, border #a3a9b0, route #343c47. No colored UI accents. Region-specific map colors and layer swatches remain independent. Keep actual image in full color.
Large bold tightly tracked headline 64–100px desktop / 40–54px mobile, restrained 12px uppercase labels, 16–18px description, 32–44px story title. Fluid margins 20px mobile to 48px desktop, max-width 1320px. Spacing 8/12/16/24/32/48/64. Sharp cards, 0–4px control radii, no card shadows or gradients. Thin horizontal rules and asymmetric editorial caption layout. Single featured story should feel intentional and substantial, not a tiny tile in an empty grid.
Keep neutral compact map legend, language control, locator chip and overview panel consistent. Collapsed menus stay compact. Preserve all map routes, layer toggles, real-road connections, image and audio functionality in implementation.
Motion: subtle 150–250ms ease for hover, focus/underline, respect reduced motion. Visible keyboard focus and mobile reflow without overflow. Keep language switching in both languages and all existing navigation destinations.
